## 项目概览

天象智研是一个气象数据机器学习项目。当前公开的 Notebook 记录了数据清洗、探索性分析、异常值检测、特征重要性分析，以及针对 `condition_text` 的模型实验。

当前主要任务是根据观测特征识别天气状态，例如晴天、多云或降雨。未来时段的天气预测是后续研究方向，需要独立的时间划分与验证设计。

## 数据与特征

Notebook 从 `GlobalWeatherRepository.csv` 读取数据。原始观测包含地理位置、气象、空气质量和天文信息；这些是数据字段类别，不代表所有字段都进入了最终模型。

| 范围 | 示例 |
| --- | --- |
| 气象观测 | 温度、风速、气压、降水、湿度、云量、能见度、紫外线指数 |
| 空气质量 | 一氧化碳、臭氧、二氧化氮、颗粒物及空气质量指数 |
| 预测目标 | `condition_text`，表示观测对应的天气状态 |

随机森林实验使用数值气象与空气质量特征，并对目标天气标签进行编码。具体字段及处理步骤以 Notebook 代码为准。

## 实验流程

1. **整理数据**：统一部分地点记录与天气状态标签，查看数据分布。
2. **检查异常值**：对数值特征应用 Isolation Forest，并构建筛选掩码。
3. **探索特征**：通过可视化、相关性与特征重要性分析理解输入信息。
4. **建立模型**：Notebook 包含多个模型实验，其中随机森林分类器设置为 `n_estimators=100`、`random_state=42`。
5. **分析结果**：保留实验输出与比较过程，为进一步完善评估提供依据。

## 当前评估与后续工作

现有实验采用随机训练/测试划分，部分评估代码仍将 MSE、R² 等回归指标应用于编码后的天气类别。下一步应补充准确率、宏平均 F1、混淆矩阵等分类评估，并检查异常值筛选后的特征与标签是否对齐。

面向未来天气预测时，还需要按时间划分数据，检查数据泄漏，并建立可比较的基线。深度学习时序模型和 REST API 服务目前仍是后续计划。
